# Security policy

Site Security Auditor is intended for authorised administrators auditing the WordPress installation on which it runs. It performs posture checks; it does not guarantee that a site is secure or detect malware.

## Reporting a vulnerability

Do not include live credentials, private keys, personal data or a third-party target in an issue. Report suspected vulnerabilities privately through the repository's GitHub Security Advisories page. Include the affected version, impact and a safe reproduction where possible. Maintainers should acknowledge reports and coordinate a fix before public disclosure.

The project has no published response-time or supported-version commitment yet. Do not rely on this pre-release project as an emergency response service.

## Safe use

Use only on sites you administer or are authorised to assess. Network lookups are optional and disabled by default. The plugin should not change site files, users, roles, updates or server configuration.
